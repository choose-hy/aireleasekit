# PM Launch Scorecard

A useful AI launch gate should answer:

- What user workflows must pass before launch?
- Which failures are launch blockers?
- Which risks can ship with a warning?
- What privacy, policy, cost, and latency thresholds matter?
- What evidence should reviewers see in a PR?

AIReleaseKit encodes those answers in `quality_bar`, `release_policy`, and generated eval cases.
